# Reproducing the manuscript

This folder holds the code that produces the tables and figures of

> Nonomiya Y. Risk-set reconstruction balance: zero-targeted diagnostics for
> artificial censoring in clone–censor–weight analyses. In preparation.

It covers the simulation study (Parts 1–3), the supplementary checks of the
null reference (Supporting Information, Appendix S2) and the case study on
the Webster-Clark Synthetic Medicare cohort linked to the CMS DE-SynPUF
claims (Appendix S3). The folders `analysis/`, `output/` and `data-raw/` are
excluded from the package build.

## Setup

Run every script from the repository root, which is the package root. Each
script loads the development version of the package with
`pkgload::load_all(".")`.

Packages needed in addition to the package's own imports:

| Package | Used by |
|---|---|
| `pkgload` | all scripts |
| `haven` | case study (`wc_data.R`, `03*.R`), `02g` (part 2), `02j`, `data-raw/get_synpuf_claims.sh` (reads the SAS data file) |
| `survival` | `03_empirical_webster_clark.R`, `02j` |
| `patchwork` | `04_paper_figures.R`; `patchwork` or `gridExtra` for the dashboard plot of `03_empirical_webster_clark.R` |
| `testthat` | `tests/test-sim_scenarios.R` |

`parallel` (base R) runs the simulations with `parallel::mclapply()`; set the
number of workers with `CCW_CORES` (default: all cores but one). Results were
produced with R 4.4.3.

## Case-study data

The case study needs two public data sources; both are git-ignored and must
never be committed.

1. The cohort of the Webster-Clark CCW tutorial (no registration, about
   200 KB):

   ```sh
   git clone https://github.com/mawcpharmdphd/CCW_tutorial data-raw/webster_clark
   ```

   The scripts read `data-raw/webster_clark/Data/baseccwcohort.sas7bdat`
   (1,590 individuals).

2. The CMS 2008–2010 DE-SynPUF claims of the cohort members:

   ```sh
   bash data-raw/get_synpuf_claims.sh
   ```

   The script downloads the inpatient, outpatient, carrier and Part D files
   of all 20 DE-SynPUF samples (about 7.4 GB, discarded after filtering) and
   keeps the claims of the cohort in `data-raw/synpuf_claims/*.csv`.

`wc_data.R` (`wc_prepare()`, sourced by `03`, `03b`, `03c`, `03d` and part 2
of `02g`) links the two sources and builds the long data in 10-day
intervals. It derives three time-varying indicators for the 10 days before
each interval: `visit` (carrier claim), `outpt` (hospital outpatient claim)
and `fill` (Part D fill other than the index fill). It also derives three
depth functions of the dispensing history that are monitored but enter no
censoring model: `fill_lag` (fill in the preceding window), `fill_30` (fills
in the last 30 days) and `fill_cum` (fills since discharge). The censoring
models are `base` (the tutorial model: age, sex, renal disease), `race`
(`base` + race), `use` (`base` + `visit`, `outpt`, `fill`; the revised
model) and `full` (`base` + race + `visit`, `outpt`, `fill`).

## Scenarios

`sim_scenarios.R` defines the scenario grids. A *run* is one execution of
`02_simulation_study.R` over the grid `ccw_scenarios(<run>)`. Four runs
(`main`, `manycov`, `largerep`, `variants`) supply the manuscript.
`paper_scenarios()` maps the scenario ids of Table 2 (P1-01 to P1-13,
P2-01 to P2-06, P3-01 to P3-04) to the run scenario whose results are
reported; the table is saved as `scenarios_paper.csv`, and
`paper_scenario(id)` returns the definition of one scenario.
`sim_paper_results.R` reads the replicate-level results of given ids. The
grids of the runs are saved as `scenarios_<run>.csv`.

## Saved outputs

`output/sim/` holds the replicate-level results and settings of the four
runs (`sim_results_<run>.csv`, `sim_settings_<run>.csv`) and every summary
of the simulation study and the supplementary checks that the manuscript
cites. `output/figures/` holds the two simulation figures. With these files
the table and figure scripts run in seconds without rerunning any
simulation. The case-study outputs (`output/empirical/`) are derived from
the external data and are not included; they are regenerated by the
case-study scripts.

## Run order

Fast (seconds; read only saved outputs):

```sh
Rscript analysis/02b_simulation_tables_paper.R   # tables and figures, Parts 1-3
Rscript analysis/02d_size_adjusted_detection.R   # size-adjusted detection
Rscript analysis/02e_se_ratio_robust.R           # robust SE ratio
Rscript -e 'pkgload::load_all("."); testthat::test_file("analysis/tests/test-sim_scenarios.R")'
```

Case study (needs `data-raw/webster_clark/` and `data-raw/synpuf_claims/`;
outputs go to the git-ignored `output/empirical/`, and Figure 4 to
`output/figures/fig4_wc_rrb_profile.png`, which is therefore not included
here):

```sh
Rscript analysis/03_empirical_webster_clark.R  # estimates, RRB, weights
Rscript analysis/03b_wc_null_reference.R       # null reference, tutorial model
Rscript analysis/03c_wc_sensitivity.R          # bootstrap; models race, use, full
Rscript analysis/03d_wc_depletion.R            # depletion term (after 03)
Rscript analysis/04_paper_figures.R            # Figure 4 (after 03, 03b, 03c)
```

Simulations (long; runtimes with 40 cores in parentheses where known):

```sh
CCW_RUN=main     Rscript analysis/02_simulation_study.R  # (~2 h)
CCW_RUN=manycov  Rscript analysis/02_simulation_study.R  # (~25 min)
CCW_RUN=largerep Rscript analysis/02_simulation_study.R  # (~2.75 h)
CCW_RUN=variants Rscript analysis/02_simulation_study.R  # (~40 min)
Rscript analysis/02f_cumrrb_censored_strata.R  # needs sim_results_main.csv
Rscript analysis/02g_null_coupling_check.R     # coupling of the null reference
Rscript analysis/02j_depletion_incidence.R     # grace-period incidence (+ data)
Rscript analysis/02l_pilot_model_terms.R       # scale of the history functions
Rscript analysis/02m_pilot_g2_cause.R          # decomposition per strategy
```

`02g` and `02j` also use the Webster-Clark data (`02g` skips its case-study
part when the data are absent). After a simulation rerun, rerun `02b`, `02d`
and `02e`. The seeds are fixed in the scripts; the header of each script
lists its settings (environment variables) and outputs.
